# AegisMart Returns Policy

## Purpose

This document defines the operational interpretation of customer returns.

## Return Analysis

Returns should be analyzed using:

- Return volume.
- Return rate where sufficient order information is available.
- Return reason.
- Product.
- Product category.
- Time period.

## Investigation

An increase in returns should be investigated by examining:

1. Product concentration.
2. Return reasons.
3. Category trends.
4. Changes over time.
5. Relationship with sales volume.

## Interpretation

A high absolute number of returns does not necessarily indicate an operational problem because products with higher sales volume may naturally generate more returns.

Return rates and trends should therefore be considered where appropriate.
